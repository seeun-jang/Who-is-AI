# 🕵️‍♂️ Who Is AI? (인공지능 마피아 게임)

> **"우리 중에 인간을 흉내 내는 AI가 숨어있다!"**
> 참가자들과 대화를 나누며 위화감을 찾아내고, 숨어있는 AI를 찾아내 처형하세요.

🔗 **[💻 게임 플레이하러 가기](https://seeun-jang.github.io/Who-is-AI/)**

<br>

## 🎮 프로젝트 소개
**Who Is AI**는 웹소켓을 기반으로 한 실시간 멀티플레이어 마피아 게임입니다. 
5명의 플레이어가 모여 특정 '제시어'에 대한 경험담을 나누고, 자유 토론을 거쳐 가장 AI 같아 보이는 플레이어를 투표로 색출하는 심리 추리 게임입니다.

<br>

## ✨ 핵심 기능

* **🌐 실시간 멀티플레이 통신**
  * 웹소켓을 활용한 5인 실시간 게임 매칭 및 턴 동기화
* **💬 턴제 발언 & 자유 토론**
  * 라운드별 제시어에 맞춰 플레이어마다 순차적으로 발언권 부여
  * 모든 발언이 끝난 후, 타이머와 함께 실시간 자유 토론 진행
* **📓 실시간 탐정 수첩**
  * 게임 중 언제든 열어볼 수 있는 슬라이드 패널 제공
  * 플레이어별 의심 체크 및 메모 기능 지원
  * 수첩에 기록한 상태가 게임 보드 위 말풍선에 즉각 시각화
* **⚖️ 투표 및 처형 시스템**
  * 투표를 통한 용의자 지목 및 10초간의 최후의 발언 기회 부여
  * 최종 사면/처형 투표를 통한 게임 승패 판정(AI Win / Human Win)

<br>

## 🛠️ 기술 스택

* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Backend 통신:** WebSocket API
* **Deployment:** GitHub Pages

<br>

## 🕹️ 게임 진행 흐름

1. **대기방:** 5명의 플레이어가 접속할 때까지 대기합니다.
2. **제시어 공개:** 라운드가 시작되면 이번 턴의 제시어와 자신의 플레이어 번호가 공개됩니다.
3. **순차 발언:** `NOW SPEAKING` 차례에 맞춰 제시어에 대한 자신의 경험담이나 생각을 짧게 발언합니다.
4. **자유 토론:** 모든 플레이어의 발언이 끝나면, 제한 시간 동안 자유롭게 의견을 나눕니다.
5. **투표:** 가장 의심스러운 플레이어를 투표하여 처형대에 올립니다.
6. **최후의 발언 & 판결:** 처형대에 오른 플레이어는 10초간 유언을 남기며, 이후 최종 판결을 통해 정체(인간/AI)가 공개됩니다.
